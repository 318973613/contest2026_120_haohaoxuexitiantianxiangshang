## 一、为什么要改

官方《大赛总览》规定：**含语音唤醒的项目必须统一使用「你好，openvela / Hello，openvela」**。
本项目此前的实现是「你好小米」，属于**合规硬伤**——不是体验问题，是规则问题。

| 2 | `packages/ai_agent/src/voice/voice_wake.c` | 启动日志 | 展示 |
| 3 | `packages/ai_agent/src/channels/cmd_voice.c` | `voice_wake_start` 回显 | 展示 |

## 二、改成了什么

### 匹配逻辑

```c
static const char* phrases[] = {
    "你好openvela", "helloopenvela", "小维同学", "小维", "学习助手"
};
```

三个决定，每个都有理由：

1. **短语表里不写逗号。** 归一化过程本来就会剥掉空格和 `，`、`、`，所以表里存
   无分隔符形式才能命中。这一点不是风格选择，是匹配正确性的前提。
2. **加了 ASCII 大小写折叠。** 云端 ASR 完全可能返回 `OpenVela`、`OPENVELA`
   或 `openvela`。原来的 `strstr` 区分大小写，只认最后一种。现在归一化时对
   `< 128` 的字节做 `tolower`，三种写法都能唤醒；UTF-8 的首字节和续字节都
   `>= 128`，原样透传，不会被误伤。
3. **删掉「你好小米」「小米同学」，保留中性旧别名。** 品牌冲突的两个必须删，
   这是规则针对的对象。`小维同学 / 小维 / 学习助手` 是本项目自己的叫法
   （小维来自 Vela），留作兼容，避免老用户改了习惯就唤不醒。

同时 `voice_ui_bridge.h` 的注释同步改写，说明新短语和兼容范围。

### 界面与日志

其余 6 处展示文案统一为「你好，openvela」，带全角逗号，与规则原文一致。

### 一个刻意不动的地方

`study_terminal_main.c` 里还有一处 `"小米 MiMo"`，那是**模型品牌名**
（Xiaomi MiMo），不是唤醒词。规则约束的是唤醒词，改掉它反而是错的，所以保留。

## 三、字体与排版确认

改之前先确认了「openvela」这 8 个 ASCII 字母能不能显示：

- `lv_font_study_16.c` 是 CJK 子集字体，`-r` 参数只列了 `0xb7`、`0x3002`、
  `0x4e00~0x9ea6` 若干字和 `0xff0c`，**不含 ASCII**；
- 但它带 `--lv-fallback lv_font_montserrat_16`，ASCII 走 Montserrat 回退渲染，
  所以 `openvela` 能正常显示（首页的 `MiMo`、`CPU` 走的就是这条路）；
- 全角逗号 `0xff0c` **在**子集里，所以「，」不会变成方框。

排版也核过了：AI 页副标题是 `LV_LABEL_LONG_CLIP` + `LV_PCT(100)`，只裁剪不换行，
不会撑破布局；设置页开关行的标题在 `flex_grow` 列里，480px 下可用宽度约 392px，
新文案约 162px，放得下。

## 四、测试

主机测试同步更新，并新增**合规回归断言**：

```c
assert(voice_wake_matches("你好 openvela") && voice_wake_matches("你好，openvela"));
assert(voice_wake_matches("Hello，OpenVela") && voice_wake_matches("小维同学"));
assert(!voice_wake_matches("你好"));
/* Contest compliance: the Xiaomi-branded wake words must no longer match. */
assert(!voice_wake_matches("你好小米") && !voice_wake_matches("小米同学"));
```

也就是说，「你好小米」必须**唤不醒**设备，这条被固化成断言，以后谁改回去都会挂。

`verify_pair.py` 里原本有一条硬编码断言要求二进制**必须含**「你好小米」，
这轮反过来改成「必须不含」，并保留「必须含」新短语。

同句追问的裁剪逻辑也复算过：回映射公式 `offsets[strlen(phrase)-1] + 1` 在新短语
长度下依然成立，所以「你好，openvela，介绍 hello world」仍能正确裁出
「介绍 hello world」。

**结果：83 组全绿**（voice 23、chat 3、cron 23、focus 8、api 4、UI 480×320 与
1280×800 各 11），0 失败、0 ASan/UBSan 命中。
