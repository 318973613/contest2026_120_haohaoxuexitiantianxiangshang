# Study Terminal QEMU Screenshots

These PNG files are real 1280x800 RGB565 framebuffer captures from the
`goldfish-arm64-v8a-ap` QEMU target. They contain no API key, authorization
header, password, or emulator console token.

- `study-terminal-home.png`: focus timer, task count, network, and reminder.
- `study-terminal-status.png`: live heap, network, uptime, and components.
- `study-terminal-tasks.png`: task counts and Study Assistant task rows.
- `study-terminal-ai.png`: MiMo provider, model, tool, and Skill state.
- `study-terminal-settings.png`: reminder, refresh, animation, and debug toggles.

The screenshots are runtime evidence only. The application remains composed of
interactive LVGL controls and live values; these PNG files are not used as UI
backgrounds.
