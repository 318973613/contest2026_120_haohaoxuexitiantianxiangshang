# Source

This directory is reserved for project-owned, platform-independent source
modules shared by the display application and ai_agent tools.

Build-facing openvela applications remain under `app/` and are mapped into the
openvela build tree by the contest manifest.

Do not place modifications to public `nuttx`, `packages`, or `vendor`
repositories here. Public-repository changes must follow the contest fork and
pull-request process.
